# CutGenius

CutGenius is a high-converting automated web landing page designed to transform long videos into viral short clips (Reels, TikToks, Shorts) using advanced Artificial Intelligence.

## Features
* **AI-Powered Video Clipping:** Turn hours of footage into bite-sized viral clips instantly.
* **Seamless Monetization:** Integrated directly with a secure Stripe Payment Link for instant €25 subscriptions.
* **Modern Minimalist UI:** Built with a sleek dark-themed responsive design optimized for conversions.

## Business & Deployment
* **Tech Stack:** Pure HTML5, CSS3, and hosted effortlessly on Vercel via GitHub.
* **Monetization Model:** Ready-to-use digital service business model. Ideal for quick deployment, scaling, or resale to interested buyers.
