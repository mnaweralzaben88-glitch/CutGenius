# 🎬 CutGenius | AI Video Editor

> The ultimate next-generation AI-powered platform to convert long videos into viral Reels, Shorts, and TikToks in one click.

---

## 🌟 Overview / نظرة عامة
**CutGenius** is a modern, responsive web application designed for content creators, podcasters, and marketers. It automates video clipping, resizing, and smart highlighting using state-of-the-art artificial intelligence.

**CutGenius** هي منصة ويب حديثة ومتجاوبة مصممة خصيصاً لصناع المحتوى، البودكاست، والمسوقين لتحويل الفيديوهات الطويلة إلى مقاطع قصيرة رابحة باستخدام الذكاء الاصطناعي.

---

## ✨ Key Features / الميزات الرئيسية
- 🌍 **Multi-Language Support / دعم متعدد اللغات:** Seamlessly switch between Arabic (RTL), English, French, and Spanish.
- ⚡ **AI-Powered Processing / معالجة بالذكاء الاصطناعي:** High-accuracy automated smart cutting and video optimization.
- 🚀 **Cloud-Ready / جاهز للرفع السحابي:** Easily deployable on Vercel with instant GitHub integration.
- 💳 **Flexible Pricing Plans / خطط أسعار مرنة:** From free trial packages to professional **Pro** tiers with 4K ultra-fast exports and VIP support.

---

## 🛠️ Tech Stack / التقنيات المستخدمة

- **FontAwesome 6** (Modern vector icons)
